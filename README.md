# 🌐 Personal Portfolio Website

## 📌 Overview

This is my personal portfolio website designed to showcase my projects, technical skills, and UI/UX design expertise. It highlights my work in frontend development and provides an interactive user experience.

## 🚀 Features

* Responsive design for all devices 📱💻
* Clean and modern UI/UX ✨
* Project showcase section with descriptions
* Smooth navigation and animations
* Light and dark themes that follow the system preference
* Contact form powered by Web3Forms

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## Contact Form

The contact form submits through Web3Forms. Manage the recipient email and access key in the Web3Forms dashboard.
